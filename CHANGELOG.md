## [0.1.0] - 2026-11-08
### Added
- Feature: Public launch catalog at `/launches` showing available rocket launches.
- Integration: `ApiClient` for AstroBookings API with error handling.
- Web: Server-rendered JSP views for the catalog, with search and sort.
- Tests: Unit tests for integration/service/web layers and Playwright E2E tests for ACs.
